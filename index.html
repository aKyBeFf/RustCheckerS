Подключить Rust+

beta

Подключено. Заходи в игру → Rust+ → Pair with server - серверы появятся ниже сами. Токен из расширения живёт ~14 дней: если серверы перестали обновляться, получи новый в расширении и нажми «Перепривязать».

  1. Поставь расширение rustPlusPlus Credential Application и войди через Steam - оно сделает всё за тебя.
  2. Скопируй выданные credentials и вставь их ниже - один раз.
  3. Зайди в игру → меню Rust+ → Pair with server. Сервер появится тут сам.

Расширение работает у тебя в браузере - данные Steam никуда не передаются, к нам приходят только FCM-креды для приёма пейрингов.

Политика данных

RustChecker - сервис для проверки серверов и игроков Rust. Ниже - какие данные мы собираем и зачем.

Что мы храним

  • Аккаунт: логин, email и пароль (пароль хранится в зашифрованном виде на стороне Supabase).
  • Привязки: SteamID и данные Rust+ паринга, если ты их добавил, - только для работы функций сервиса.
  • Telegram: ID чата, если ты привязал бота, - чтобы присылать уведомления.
  • Отслеживания: каких игроков и на каких серверах ты отслеживаешь.

Зачем

  • Показывать статус серверов и игроков (данные берутся из публичного API BattleMetrics).
  • Присылать уведомления в Telegram о заходе/выходе игрока.
  • Управление аккаунтом и подпиской.

Что мы НЕ делаем

  • Не продаём и не передаём твои данные третьим лицам.
  • Не собираем данные, не относящиеся к работе сервиса.

Удаление

Ты можешь в любой момент отвязать Steam/Telegram и удалить отслеживания. Для полного удаления аккаунта - напиши нам.

Проект никак не связан с Facepunch Studios и Rust. Все товарные знаки принадлежат их владельцам.
